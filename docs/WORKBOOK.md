# Meal-planning teaching example

Open `examples/meal-planning-workbook.pdf` in a PDF reader that supports form fields. You can also print it.

The first part contains blank pantry, weekly-plan and shopping-list worksheets. The second part shows one illustrative completion. The example is not a business with verified sales or a nutrition plan.

Try the blank fields, save a copy under a new filename, close it and reopen it in your own PDF reader. Browser PDF viewers can differ in how they save form values.

The source is `tools/create-example-workbook.py`. Rebuilding the PDF is optional and requires Python and ReportLab. Running the source stops if its output already exists, so preserve or choose a different output filename before rebuilding.

This example helps you inspect what a small digital product contains. The book's process still requires checking a real buyer's problem, product usefulness, delivery and economics.
