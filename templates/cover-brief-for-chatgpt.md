# Cover Brief for ChatGPT

Master Prompt 2 writes this brief for you. This is the shape it takes. Open a free ChatGPT account, paste the brief, and ask for the front cover first, then the back.

## The brief

```
Make a book front cover image.

Title (exact spelling, must be readable even as a thumbnail): [TITLE]
Subtitle (exact spelling): [SUBTITLE]
Author name (exact spelling): [AUTHOR NAME]

Who it is for: [READER, for example electricians who train apprentices]
The feeling: [calm, practical, trustworthy]
Main image idea: [one simple image, for example a worn electrician's notebook beside a tablet, warm light]
Colors: [2 or 3 colors]
Style: clean, professional, plenty of empty space around the title.
Size: portrait, ratio 1.6 to 1 (for example 1600 x 2560 pixels).
Do not add: fake awards, bestseller badges, star ratings, or any text other than the three lines above.
```

## Back cover brief

```
Now make the back cover to match the front. Same colors and style.
Include this text exactly, with no changes:
[HOOK: one short line starting with the reader's problem]
[THREE SHORT BULLETS]
[ONE LINE ABOUT THE AUTHOR]
Leave an empty area for a barcode if needed.
```

## Fixing mistakes without ruining the rest
Say: "Keep everything exactly the same. Change only [the one thing]." Ask for one change at a time.

## Check before you use it
- [ ] Every word spelled correctly (zoom in)
- [ ] Readable at thumbnail size
- [ ] No fake badges, awards or reviews
- [ ] Right size for the place you upload (see KDP's current guidance)
- [ ] You are allowed to use what the tool produced (read its terms); disclose AI-generated images where the store asks you to
